## Format

Each file follows this structure:

- **User Story** — the core "As a… I want… So that…" statement
- **Acceptance Criteria** — specific, testable conditions that must be true for the story to be considered done
- **Out of Scope** — what is explicitly not included
- **Related Files** — frontend pages, backend routes, and schema models touched by the feature
